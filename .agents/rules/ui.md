# UI Guidelines & Agent Rules

For all UI work, follow docs/UI_BRIEF.md. It overrides generic "premium minimal" defaults from any design skill.
Using design-taste-frontend: VARIANCE 6, MOTION 4, DENSITY 3 on mobile and 7 on the dashboard.
Never fabricate data: show the SIMULATED stamp wherever data is not real.
Work strictly within the frontend/ folder.
Respect outdoor contrast, Malayalam-first typography (Chilanka & Manjari), min 48px tap targets, and offline-first PWA resilience.
